隱私權政策

最後更新日期：2025年10月16日

1. 簡介

本隱私權政策說明 Threads Content Analytics（以下簡稱「本應用程式」）如何收集、使用和保護您的個人資料。 我們致力於保護您的隱私權，並遵守所有適用的資料保護法規。

2. 我們收集的資料

本應用程式透過 Meta Threads API 收集以下資料：

  • Threads 貼文內容：您在 Threads 上發布的文字、圖片和影片
  • 貼文元數據：發布時間、貼文 ID
  • 績效數據：按讚數、評論數、分享數、觸及數等洞察報告數據
  • 基本個人資料：用戶名稱、個人檔案圖片、粉絲數

3. 資料使用目的

我們使用收集的資料用於以下目的：

  • 在分析儀表板中顯示您的 Threads 內容和績效數據
  • 生成內容表現趨勢報告
  • 幫助您了解哪些內容最受歡迎
  • 提供內容優化建議

4. 資料存儲與安全

您的資料僅用於顯示給您本人。我們採取以下安全措施保護您的資料：

  • 所有資料傳輸使用 HTTPS 加密
  • 使用 Meta 官方 OAuth 2.0 認證機制
  • 定期進行安全性審查

5. 資料分享

我們絕不會將您的個人資料分享給任何第三方。 您的資料僅供您個人使用，不會用於廣告、行銷或其他商業目的。

6. 您的權利

根據資料保護法規，您擁有以下權利：

  • 存取權：您可以要求查看我們持有的您的個人資料
  • 修改權：您可以要求更正不正確的資料
  • 刪除權：您可以隨時要求刪除您的所有資料
  • 撤回授權：您可以隨時在 Threads 設定中撤回對本應用程式的授權

7. 資料刪除

如果您想要刪除我們持有的您的所有資料，請執行以下步驟：

  1. 前往 Threads 應用程式的「設定」
  2. 選擇「帳號管理中心」
  3. 在「你的資訊和權限」中，撤回對 Threads Content Analytics 的授權

撤回授權後，您的所有資料將在 30 天內從我們的系統中完全刪除。

8. 與 Meta 的關係

本應用程式使用 Meta Threads API 來存取您的 Threads 資料。 我們遵守 Meta Platform Terms 和 Meta Platform Policy。

9. Cookies 和追蹤技術

本應用程式使用必要的 Cookies 來維持您的登入狀態和應用程式功能。 我們不使用任何追蹤或廣告 Cookies。

10. 未成年人隱私

本應用程式不針對 13 歲以下的兒童。如果我們發現收集了未成年人的資料， 將立即刪除相關資料。

11. 隱私權政策變更

我們可能會不時更新本隱私權政策。任何重大變更都會在本頁面上公告， 並更新「最後更新日期」。
